## 1. Fixed prices and offers, remove auctions

Replace all auction/bidding behavior with a seller-set asking price and a simple offer flow. Buyers can offer an amount; sellers can accept or decline. Do not introduce bidding rounds, competing-bid rankings, auction timers, or automatic highest-bid winners. Preserve a straightforward purchase-at-asking-price path through booking. An accepted offer establishes the agreed price; booking selects the meetup time and campus location. Work with the booking implementation so acceptance cannot sell an item twice or create conflicting reservations. Remove auction controls, bid feeds, auction copy, and new auction API actions. Inspect existing auction records and propose a non-destructive migration instead of deleting history or silently changing commitments. Prevent stale clients from placing bids. Preserve applicable payment behavior without enabling real money. Test ownership, invalid prices, stale offers, expiry, and simultaneous acceptances. Coordinate schema/API changes with chat 2 before implementing.

## 2. Seller availability and exact campus meetup booking

Implement seller availability for today and the next rolling 24 hours. Buyers see a clear calendar or time-slot chart and choose a specific available time and a valid campus place; both participants see the exact agreed time, place, listing, and price. Use campus-local display times and unambiguous stored timestamps. Reuse existing reservation rules where possible and define a clear confirmation step. Validate slot duration against the existing product behavior; make any new duration explicit rather than hiding an assumption. Prevent seller double-booking across listings, past/out-of-window selections, stale availability, and concurrent reservations. Coordinate asking-price and accepted-offer flows with chat 1. Cancellation/rescheduling must update availability and notification events. Listings should expire after 24 hours, with server enforcement, and expired listings cannot take new offers or bookings. Confirmed meetups must remain accessible even after listing expiry. Keep a durable transaction record rather than erasing confirmed bookings. Map integration is deferred; use campus place selection now. Test boundaries, concurrent booking, cancellation, rescheduling, and expiry.
