# Campus Marketplace Build Brief (as supplied by the founder, 2026-09-14)

See the original brief text in the project conversation; key constraints are summarized in ARCHITECTURE.md "Non-negotiables" and CONTRACT.md. Acceptance criteria for the first build:

1. A person can browse clearly marked sample listings before signing in.
2. A test seller can create and edit a persisted listing with photos and pickup availability.
3. A second test user can view the listing, message the seller, and request a spot and time.
4. The seller can accept, and both users see the same reservation and meetup details.
5. A second buyer cannot simultaneously reserve the accepted item.
6. Cancellation and rescheduling update both users consistently.
7. Handoff confirmation changes the item to sold without fabricating a payment event.
8. Reporting and blocking are available and access controls protect private data.
9. The main screens work at common iPhone sizes, including keyboard and photo-picker flows.
10. The handoff includes launch instructions, what was actually tested, screenshots or a preview where available, and a clear list of simulated or unfinished integrations.
